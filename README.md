# Selenium Cucumber UI Automation

A Java 17+ UI automation framework using Selenium 4, Cucumber 7, JUnit 5, Maven, and PicoContainer.
It includes reusable page actions, explicit waits, thread-local WebDriver management, failure screenshots,
Cucumber HTML/JSON reports, and Allure result output.

## Prerequisites

- JDK 17 or newer
- Maven 3.8+
- Chrome, Firefox, or Microsoft Edge

Selenium Manager, included with Selenium 4, resolves the browser driver automatically. The browser itself
must be installed.

## Run the scenarios

Run all scenarios (Chrome by default):

```shell
mvn test
```

Run a tag or a single application:

```shell
mvn test -Dcucumber.filter.tags="@smoke"
mvn test -Dcucumber.filter.tags="@swag-labs"
mvn test -Dcucumber.filter.tags="@playground"
```

Choose a browser, enable headless mode, or override the explicit-wait timeout:

```shell
mvn test -Dbrowser=firefox -Dheadless=true -Dtimeout.seconds=45
```

Supported browser values are `chrome`, `firefox`, and `edge`. Browser settings, wait timeout, and
application URLs can also be changed in
[`src/test/resources/config.properties`](src/test/resources/config.properties); matching Java system
properties take precedence.

## Reports

- Cucumber HTML: `target/cucumber-reports/cucumber.html`
- Cucumber JSON: `target/cucumber-reports/cucumber.json`
- Combined Masterthought HTML (generated by `mvn verify`): `target/cucumber-html-reports`
- Allure results: `target/allure-results`

To view the Allure report, install the Allure command-line tool and run:

```shell
allure serve target/allure-results
```

Failed scenarios attach a PNG screenshot to the Cucumber scenario and save a copy under
`target/screenshots`.

## Framework layout

```text
src/test/java/com/example/ui/
  hooks/        Scenario setup, teardown, and failure screenshots
  runner/       JUnit Platform suite
  steps/        Cucumber step definitions
src/main/java/com/example/ui/
  config/       Framework configuration
  driver/       Thread-local browser lifecycle and browser factory
  pages/        Reusable base page and application page objects
src/test/resources/
  features/     Swag Labs and UI Testing Playground scenarios
  config.properties
  junit-platform.properties
```

JUnit Platform runs scenarios concurrently with a fixed pool of two workers. WebDriver state is isolated
per worker thread.
